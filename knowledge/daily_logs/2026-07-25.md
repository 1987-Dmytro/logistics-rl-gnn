**A. Provenance and falsifiability (`scripts/demo.py`)**
- A banner at startup: the checkpoint path + sha256 + the training date + a link to
  [[0007-phase6b-congestion-training]]. The sha is checked against the provenance of THE summary the
  durable numbers come from (`system_metrics.json`); no weights / a mismatch → `SystemExit` pointing at
  `--no-model`. There is no silent fallback to the heuristic (prohibition #4).
- Steps [2/5] and [4/5] print the portfolio candidate table (source · n · best · mean ·
  +polish · who was chosen) — out of the costs ALREADY computed by the scorer (`take_best(scores_out=…)`),
  so as not to inflate the measured re-plan latency.
- `--no-model` = a portfolio without RL candidates + the line "with the model vs without".

**The main finding of the day (methodological, → [[honest-asymmetric-verdicts]] lesson 4):** the first version
of the line "model contribution · re-plan" took greedy+polish FROM the portfolio with the model. That makes
Δ ≤ 0 **identically** (its price enters the same `min`, and the polish budget is split across the top-M) — the
metric could not show "the model made it worse". An adversarial review proved it; after the fix (a separate
`PortfolioPlanner(None)` with the full budget) the default run prints: the day plan **−52.7 €** (−8.2 %),
the re-plan **+5.8 €** (+1.2 %) AGAINST the model — exactly the durable verdict [[0012-pathB-residual-verdict]],
now reproducible in a single run.

**B. Scenarios (`src/logistics_rl_gnn/config/scenario.py` + `scenarios/*.yaml`)**

  (names with fuzzy / stop-id / all) · demand overrides · fleet {K,Q} · events. Typos (fields, fleet,
  params) and ambiguous names → a clear error, not a silent default.
- K/Q/the start hour are carried by `Instance.meta` (`im.fleet_of`/`dispatch_offset_min`): the defaults of
  `VRPEnv`/`polish`/`ortools_routes` bind at `def` time, so otherwise the scenario fleet
  would be lost silently. The guard: `vehicles_used ≤ K`.
- `scenarios/friday_south.yaml` (14 southern pharmacies, K=2 → 201.3 €, on-time 100 %, unserved 0) and
